# MegaHUB

MegaHUB is a Windows desktop app that brings your entire game library, no matter where it comes from, into one place. It's DERIVA's sibling project, built for people whose games are spread across Steam, Epic, GOG, Battle.net, Riot, Xbox and a handful of other launchers, plus a ROM folder that never quite found a decent home.

The underlying idea is simple. There's already too much friction in opening five different programs just to remember what you have installed and where. MegaHUB scans all of that automatically and shows it to you as a single library, with cover art, playtime, achievements and deals, all in the same place.

## Unified library

MegaHUB detects what you have installed on Steam, Epic Games, GOG, Battle.net, Riot Games, Xbox (including Game Pass and UWP games), Rockstar Games Launcher, Ubisoft Connect and EA App. You don't need to log in to each one separately inside MegaHUB: it reads what those launchers have already saved on the system and builds the library from there.

Everything can be viewed in dock format, as a grid of cover art, or in list format, more compact for large libraries. There are filters by platform, by genre, and a search bar that scans the whole library at once, no matter which launcher each game lives in.

## Retro mode and emulation

This is probably the most ambitious part of the project. MegaHUB organizes and launches games for thirty-seven different systems, from consoles of the eighties like the Atari 2600 or the ColecoVision to PlayStation 3 and Xbox 360, including arcade, Neo Geo, Game Boy, Dreamcast, Nintendo 64, Nintendo 3DS and many more.

The app creates a folder organized by console inside your Documents folder, with a clear structure for emulators and ROMs. If you already have your emulators or your collection on another drive, you can point it there instead of moving everything. MegaHUB never downloads or distributes BIOS files or ROMs, since those are copyrighted files, but it can let you know if a system is missing the BIOS it needs to boot and where to put it.

For systems that run under RetroArch, MegaHUB can download the matching core directly from RetroArch's official build server, and it can also install visual themes for the menu, always asking for confirmation before downloading anything. For consoles that use standalone emulators, like PS2, PS3, GameCube, Wii, Xbox or Xbox 360, there's automatic download when a verified, portable source exists, and a direct link to the official page when there isn't.

Cover art and game info for retro titles come from the same thumbnail repository RetroArch itself uses, with no API key needed. When the filename alone isn't enough to know what game it really is, MegaHUB can read the ROM's internal header or the disc image to identify it precisely, instead of relying on how the folder happens to be named.

## Achievements and progress

MegaHUB combines several achievement sources depending on where each game comes from. For Steam it uses the real hours the launcher itself already tracks. For games launched from MegaHUB in retro mode, it measures the actual session from start to finish. For the rest of the launchers, which open through an external protocol and don't hand back any process to watch, MegaHUB can only log when you launched something — it never makes up a duration it can't measure.

On top of that there's a proprietary achievement engine, with levels based on hours played both globally and per game and per console. There's also an integration with RetroAchievements for people playing ROMs through RetroArch, reading of real Xbox 360 gamerscore when emulating with Xenia, and reading of real PlayStation 3 trophies when emulating with RPCS3. None of this is made up: every number comes from a real file generated by the emulator or the launcher itself.

## Deals

There's a deals section that queries CheapShark, a free public API that tracks prices on Steam, GOG, Epic Games and a handful of smaller stores. Besides showing active discounts, MegaHUB builds a list of recommendations based on which microgenre you play the most, cross-referencing your real Steam hours with a hand-curated map of which games belong to which microgenre — something Steam doesn't distinguish on its own beyond broad categories like action or RPG.

## Requirements and performance

MegaHUB can read your computer's real specs — processor, memory and graphics card — and compare them against each game's minimum and recommended requirements to give you an idea of whether your system can run it. For games that aren't on Steam, it looks up their Steam equivalent just to get those requirements, since that's the only public source that publishes them in a structured way. For the handful of Riot games, which don't have a requirements API, the information is entered by hand from their official support pages.

For the most demanding console emulators, like PS2, PS3, Xbox, Xbox 360, GameCube and Wii, MegaHUB can apply resolution and performance presets directly to each emulator's actual configuration, meant to get you closer to better visuals without having to go tweaking config files by hand.

## Connection with DERIVA

MegaHUB works well together with DERIVA Companion, DERIVA's desktop app. When both are running, MegaHUB tells DERIVA in real time what you're playing, no matter if the game comes from Steam, another launcher or an emulator — something that used to only happen with Steam games. That information feeds your profile map in DERIVA, your Discord Rich Presence and your recent achievements.

The communication goes both ways. While you play, the DERIVA Companion cat can keep showing up over the emulator window even in fullscreen, something that normally no overlay manages to do over a game in exclusive mode. If either app isn't installed, the other keeps working exactly the same, without depending on the connection.

## Other things it brings

The app has a short wizard for the first time you open it, which helps you connect your first launcher and pick a visual theme without overwhelming you with options. You can navigate the whole library with keyboard or a connected controller, meant to be used from the couch just like any console. There's a profile screen with your overall stats, and a backup feature that exports your actual settings, your hand-picked paths and your achievement progress to a single file, so you can carry them to another computer without depending on any cloud.

Nothing in MegaHUB connects to paid services or asks for your credentials for each launcher. Everything it reads, it reads from what you already have installed on your own machine. And when something needs a key, like cover art from SteamGridDB or the extended catalog from TheGamesDB, that key is yours, free, and optional: without it, those specific features simply don't turn on, and the rest of the app keeps working normally.
