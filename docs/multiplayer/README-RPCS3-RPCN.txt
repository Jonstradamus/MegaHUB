MULTIPLAYER — RPCS3 + RPCN (PSN emulation)
===============================================
Applies to: PS3.

What RPCN is
-------------
RPCN is a community server (free, open source) that reimplements the
P2P "matchmaking" piece that the PlayStation Network used on PS3 — it's
not Sony's real PSN, it's a parallel network built by the RPCS3
community so that certain games' online modes work again.

Important limitation (read this before getting excited about a specific
game)
----------------------------------------------------------------------
RPCN can only revive games that used direct P2P matchmaking between
consoles. Games that depended on a DEDICATED server owned by Sony or the
developer (not P2P) will NOT have online play unless a fan-made private
server exists specifically for THAT game — look up your game's name on
the RPCS3 wiki to see its real online compatibility status before
setting up a match with friends.

How to enable it
-----------------
1. Open RPCS3 (without a game loaded yet).
2. Settings > Network > change "Connection Status" from "Disconnected"
   to "RPCN".
3. Create a free account on the RPCN website (search "RPCN sign up" —
   it's a simple registration, no payment info needed).
4. Log in with that account from RPCS3 (same Network menu).
5. Open your game normally — if the title supports P2P, the game's
   online mode should recognize the connection just like on a real PS3.

To play with your friends
----------------------------
Everyone must repeat the steps above (their own RPCN account each) and
have the same game. Then, add each other as friends or find the match
FROM INSIDE the game itself, exactly as you would have on a real PS3
with PSN — RPCN only replaces the network layer behind the scenes, the
game's interface doesn't change.

MegaHUB doesn't manage the connection for you — this is configured
INSIDE RPCS3, MegaHUB just leaves the game ready to open.
