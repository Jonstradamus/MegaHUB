MULTIPLAYER — Xemu + XLink Kai (System Link over the internet)
============================================================
Applies to: original Xbox.

Basic requirement
-------------------
This ONLY works with games that had "System Link" on the original Xbox
(the classic LAN mode, for playing between several consoles connected
by cable at the same house/place). Xemu doesn't emulate Xbox Live — that
service no longer exists for the original Xbox. What XLink Kai does is
"trick" the game into thinking it's on a LAN, even though that LAN is
actually built over the internet between PCs in different places.

First things first: does your game support it?
----------------------------------------
There are 142 original Xbox games with confirmed System Link support.
Look up your game's name on XLink Kai's public list (search "XLink Kai
supported games xbox") or check the back of the original box — it says
"System Link" if it has it.

Installing and setting up XLink Kai
-----------------------------------
1. Download XLink Kai (a free service) from its official site (search
   "XLink Kai download").
2. Create a free account and join an "arena" (a public or private room)
   — everyone who wants to play together must be in the SAME arena.
3. Follow the Xemu-specific setup guide on the Team XLink wiki (search
   "Xemu XLink Kai Setup") — the key step is pointing Xemu's virtual
   network at the adapter XLink Kai creates on your PC.

To play with your friends
----------------------------
1. Everyone installs XLink Kai and joins the same arena.
2. Each person opens the game in Xemu and goes into the "System Link" /
   "LAN Multiplayer" menu INSIDE the game (not in Xemu) — the game
   should see the others as if it were on the same local network.
3. If someone doesn't show up on the list: confirm they're in the same
   XLink Kai arena and that all three (Xemu, XLink Kai, and the game)
   are running at the same time.

MegaHUB doesn't manage the connection for you — this is configured
INSIDE XLink Kai, Xemu and the game itself, MegaHUB just leaves the
game ready to open.
